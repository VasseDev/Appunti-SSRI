## Lo sviluppo di internet  
Nel 1986 l'Italia di connette a internet, con il primo dominio www.cnr.it.  
Nel 1987 gli indirizzi sono già 10.000  
Nel 1989  
  
Gli elementi fondamentali di internet sono:  
- URL  
- http  
- html  
  
L'url è una sequenza di caratteri che identifica univocamente l'indirizzo di una risorsa di rete.  
```  
protocollo://[username[:password]@]host[:porta][</percorso>][?querystring][#fragment]  
```  
La risoluzione dell'URL in IP avviene tramite DNS.  
Il DNS è un database distribuito di domini.  
  
L'HTTP è un protocollo di comunicazione che permette lo scambio di informazioni tra client e server.  
I metodi sono:  
- GET: per richiedere una risorsa  
- POST: per inviare dati al server  
- PUT: per aggiornare una risorsa  
- DELETE: per eliminare una risorsa  
- HEAD: per richiedere solo l'header di una risorsa  
Browser è un applicazione client per l'acquisizione, la presentazione e la navigazione di risorse web.  
  
L'HTML (HyperText Markup Language) è un linguaggio di markup per la creazione di pagine web.  
  
In poco più di 50 anni si è arrivati a 20 miliardi di dispositivi connessi a internet.
